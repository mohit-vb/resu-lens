# ResuLens

> AI-powered resume analysis and feedback tool.

ResuLens helps job seekers understand how their resume performs by analyzing
their resume and providing AI-powered insights, feedback, and recommendations for improvement.

## ✨ Features

- 📄 Upload and analyze resumes
- 🤖 AI-powered resume analysis
- 📊 Resume scoring and insights
- 💡 Personalized improvement suggestions
- 🎯 Identify strengths and potential gaps
- 📱 Responsive interface
- 🔐 User authentication
- 📈 Track resume analysis results

## 🚀 Getting Started

### Prerequisites

Make sure you have the required runtime and package manager installed.

### Installation

```bash
git clone git@github.com:mohit-vb/resu-lens.git

cd resulens

npm install
```
